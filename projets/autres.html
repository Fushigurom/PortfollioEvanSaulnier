EasyWork Planning — Widget Android

Java • Android • OkHttp • JWT • WebView • AppWidget

TitreEasyWork Planning — Widget Android
Descriptif Application Android native développée en Java permettant de consulter son planning de travail Easy@Work directement depuis l'écran d'accueil du téléphone sous forme de widget.

Le projet repose sur une WebView intégrée pour la connexion à Easy@Work, qui intercepte automatiquement le token JWT émis lors de l'authentification. Ce token est ensuite utilisé pour effectuer des appels à l'API REST Easy@Work via OkHttp afin de récupérer les shifts à venir.

Un widget écran d'accueil (AppWidgetProvider + RemoteViews) affiche en temps réel le prochain shift (jour, date, horaires), le délai avant celui-ci (Aujourd'hui / Demain / Dans X jours), ainsi que le shift suivant en format compact. Le design adopte un style Glassmorphism avec fond semi-transparent. Le widget se rafraîchit automatiquement toutes les 30 minutes et gère la reconnexion si le token expire.
OutilsJava, Android SDK (API 28+), OkHttp 4.12.0, org.json, JWT Bearer Token, SharedPreferences, AppWidgetProvider, RemoteViews, Android Studio
